# Contributing to Lingo

[English](CONTRIBUTING.md) | [Русский](CONTRIBUTING.ru.md)

Thank you for your interest in contributing to Lingo.

---

## Getting Started

1. Requirements: Windows 10/11, .NET 10 SDK.
2. Clone repository:
   ```bash
   git clone https://github.com/ydzeew-max/Lingo.git
   cd lingo
   ```
3. Build and test:
   ```bash
   dotnet build -c Debug
   dotnet run
   ```

---

## Workflow

1. Create a feature branch:
   ```bash
   git checkout -b feature/your-feature
   ```
2. Keep changes clean and follow Windows 11 styling in `App.xaml`.
3. Verify that `dotnet build` passes with 0 errors and 0 warnings.
4. Commit your changes and open a Pull Request.
